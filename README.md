# DevOps Pipeline - U1

Este repositório contém um pipeline de CI/CD contínuo simulado com GitHub Actions, pytest, Terraform e scripts de deploy.

## Estrutura do Projeto
- `src/`: Código fonte do projeto
- `tests/`: Testes unitários com Pytest
- `infra/`: Configuração de Infraestrutura como Código (Terraform)
- `deploy/`: Scripts de simulação de deploy
